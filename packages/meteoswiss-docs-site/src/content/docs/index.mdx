Swiss weather data for AI assistants, powered by [MeteoSwiss Open Government Data](https://opendatadocs.meteoswiss.ch/) — the same
data behind the MeteoSwiss app and website. Free, no API key.

It comes in two forms that answer the same questions: an **MCP server** with structured tools (hosted at
[meteoswiss-mcp.ars.is](https://meteoswiss-mcp.ars.is/), or run your own) and an **Agent Skill** that needs no server at all.

<CardGrid>
  <Card title="Forecasts" icon="sun">Up to 9 days, hourly detail, ~6000 Swiss locations.</Card>
  <Card title="Current weather" icon="rocket">~300 stations, updated every 10 minutes.</Card>
  <Card title="Pollen" icon="seedling">Seven species from ~15 monitoring stations.</Card>
  <Card title="Climate series" icon="document">NBCN series going back decades, plus MeteoSwiss website search.</Card>
</CardGrid>

## Quick start

```bash
claude mcp add --transport http meteoswiss https://meteoswiss-mcp.ars.is/mcp
```

Then ask: *"Wie wird das Wetter in Bern morgen?"* — other clients are covered in [Connect to the hosted server](user/getting-started/).
