# Moving meteoswiss-llm-tools to Node.js 26 LTS

**Date:** 2026-10-30
**Source:** Claude Code (Sonnet 5.5), delegated from homebot
**Session:** Max asked (Telegram, 21:08) to move his active repos to Node.js 26, the new LTS, starting with this
one. Brief: no merge, no release, no image push, no deploy.

## Summary

Node `v26.13.0` "Lithium" (2026-10-28) is the first 26 LTS (checked on nodejs.org). Every Node pin in the repo is
now 26 except the published `engines` floor, which stays at `>=22.0.0` on purpose. Lint, build, tests, the skills
check and the evals tests pass on 26.13.0, and the MCP image builds locally on `node:26-alpine`. No code changes
were needed.

## What changed

- `.nvmrc` `24.20` -> `26`; all workflow `node-version` / `NODE_VERSION` -> `26` (`pr-ci`, `pages`, `release`,
  `release-skill`, `version-packages`), step names too.
- `.devcontainer/Dockerfile` `node:24` -> `node:26`; `packages/meteoswiss-mcp/Dockerfile` both stages
  `node:24-alpine` -> `node:26-alpine`.
- `@types/node` `^25.5.0` -> `^26.0.0` in `meteoswiss-mcp` and `meteoswiss-forecast-evals` (resolves 26.6.6);
  both lockfiles regenerated (the diff is the `@types/node` / `undici-types` resolution and peer suffixes).
- Patch changeset for `meteoswiss-mcp`: the image runtime is user-visible for self-hosters.

## Decisions

- **`engines` kept at `>=22.0.0`.** `meteoswiss-mcp` is published to npm and the docs promise Node 22+. CI and the
  image now exercise 26 only, so 22 and 24 are no longer tested. If that matters, add a matrix later.
- Docs say "Node.js 22+" (the floor), so they are unchanged.

## Verified locally on 26.13.0

`pnpm --filter meteoswiss-mcp run ci` (lint, parity, build, 317 tests pass, 1 skipped), `meteoswiss-skills` test,
forecast-evals tests (82 pass), `pnpm audit --audit-level moderate` (3 low only), and
`docker build -f packages/meteoswiss-mcp/Dockerfile .` (local only, not pushed).
Not run: `test:integration` (needs the live MeteoSwiss API; runs in CI).

## Found, not fixed

`pnpm lint` in `packages/meteoswiss-forecast-evals` reports 5 prettier errors in `src/scoring.test.ts`. The file
is untouched by this change and CI runs only that package's tests, not its lint.
